Agentic AI Platform — Golden-Path Architecture

The agent lifecycle as a governed golden path: Build Time → CI → CD (non-prod) → Offline Eval → CD (prod) → Online Eval → Feedback & Continuous Improvement ↺. Every stage runs on the same Foundation Harness stack; components are labelled with the AWS / AgentCore service that implements them. The final stage loops back to Build Time — the lifecycle iterates, it doesn't end.

Scroll horizontally →. Amber blocks = platform-owned Foundation Harness; green = domain-owned; orange tag = the AWS/AgentCore service.

↺  Continuous improvement loop — Stage 7 feeds signals & actions back to Stage 1 (Build Time). The lifecycle never ends; it iterates. This is AALOE — Agentic AI Lifecycle Operational Excellence: develop → measure → improve, continuously.

Every artifact that defines an agent (prompt, tools, harness bindings, deploy params) lives in Git and flows this path — reviewed, tested, evaluated, versioned, reversible. The same stack (AI Gateway · Identity · Memory · Observability · Guardrails · Eval) is present in dev, non-prod and prod; only data sensitivity and rollout strategy change. Served at /architecture.
